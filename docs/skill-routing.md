# Skill assignments

The active NSQ catalog contains 13 user-facing skills plus nsq-flow. The earlier 28 September audit matched all 14 installed entry files to GitHub and found no differing corresponding source files across the available packages. Load the current installed instructions at execution time; this document assigns ownership rather than duplicating the skill library.

| Skill | FANN responsibility |
|---|---|
| nsq-brand-context | Source truth, reconciliation, approval scope and canonical packet |
| nsq-brand | Identity application, copy and visual consistency |
| nsq-experience | Visitor transformation, narrative and composition contract |
| nsq-design-system | Reusable tokens, components and interaction states |
| nsq-visual-assets | Product/campaign asset briefs, generation and delivery |
| nsq-interface | Implementation, responsiveness, accessibility and visual refinement |
| nsq-site-release | Applicable deployment/domain verification and release evidence |
| nsq-dispatch | Bounded executable handoffs and acceptance criteria |
| nsq-ai-team | Authorized delegation or independent review when it materially helps |
| nsq-skill-sync | Catalog checks and supported refreshes |
| nsq-flow | Proportional operating process |
| nsq-improve | Evidence-based learning from meaningful releases or repeated friction |
| nsq-presentation | Supplier or partner presentation deliverables when needed |
| nsq-droplet-ops | Dormant unless an approved server dependency actually exists |

## Complementary workflows

Imagegen and Product Design ideate support visual alternatives. Product Design image-to-code and audit support selected reference implementation and review where appropriate. Shopify merchant, Liquid, CLI and Admin skills own their respective store work. Supabase owns scoped operational-data work. Figma is optional when a design-file deliverable is useful. Sites may host an appropriate concept preview; it does not silently replace the recorded commerce platform. Documents, Presentations and Drive/Sheets support source and partner materials.

Follow the active NSQ manifest. Older archived skill names do not create parallel ownership. Web Artifacts Builder methods are carried by nsq-interface and do not dictate a replacement stack.
