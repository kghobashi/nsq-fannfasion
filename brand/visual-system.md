# Visual system

- Display and wordmark typography: Bank Gothic.
- Body and user-interface typography: Montserrat.
- Primary background: Pure Near-Black #1C1C1C.
- Surface: #232323.
- Primary accent: Champagne Gold #B29C7D.
- Structural accent: Indigo Smoke #3A3F5C.
- Light neutral and headline colour: Off-White #E8E6E0.
- The current website must contain no erotic-themed imagery.

## Source and implementation notes

The palette is retained from the previously verified FANN visual system. Bank Gothic with Montserrat is explicitly approved by Kay on 28 September 2026 and resolves the Josefin Sans and Raleway conflicts.

Design System v11 references BankGothic display tracking of 0.14em and Montserrat 300 for editorial body text. Use these as inherited visual guidance. UI weights, responsive sizing and spacing require actual readability checks; they are not established by a font filename.

`design/tokens.json` captures the approved primitive colours and font families. It does not lock page layouts or garment colours.

Existing references suggest dark fabric, architectural folds, restrained warm edge light and material detail. This is a promising reference direction, not an approved garment design or final website composition. The constellation and NSQ.global navigation in the portfolio image belong to the parent-site concept.

Saved font files named bgothm.woff2 and bgothl.woff2 exist. Confirm internal font-family names, browser rendering and distribution rights before self-hosting them. Do not copy proprietary font binaries into this public repository as part of the foundation.

The supplied FANN_Logo-2.png (1072 × 930, RGBA) is the current mark for initial use. It is a geometric warm-gold symbol, not a full wordmark. Use it as supplied; do not redraw it through image generation.
