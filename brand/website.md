# Website brief

- Governing identity: Bank Gothic, Montserrat and the supplied geometric FANN mark.
- Exact promise: Designed for Confidence. Engineered for Comfort.
- Exact tagline: Support in Style.
- Platform: native Shopify. The connected development store is 8gdtem-bi.myshopify.com, initially named My Store 5, with Horizon installed as the MAIN theme.
- Content phase: prepare the catalogue, collection architecture, editorial copy and navigation now; choose website concept direction next; build the editable theme skeleton after that.
- All product images supplied on 29 September are concept renders, not final garment photography or proof of manufacture.
- Catalogue structure: Silver, Gold and Platinum have colour variants; the four Black designs and six supplied Legacy archetypes are separate products.
- Gold has six provisional colour directions. Only Maroon has an individual garment render; the other five are represented by the palette board.
- Seasonal Editions is reserved and unpublished pending the next source batch.
- X Edition is excluded from current products, pages, imagery and navigation.
- Draft products and unpublished editorial content do not authorize checkout, preorders, publishing or a production launch.
- All customer-facing headings, body text, images, links, spacing and colour controls must be editable through native Shopify theme settings, sections and blocks.

## Editable implementation contract

Use Online Store JSON templates, reusable sections/blocks and header/footer section groups. Start from the installed Horizon block architecture when evaluating the visual concepts. Retain native product, collection, cart and contact-form behavior. Avoid a page-builder dependency, a headless frontend, whole-page Custom Liquid, baked-in image text or a single uneditable HTML page.

Keep product facts in Shopify product/variant fields. Keep editorial page composition in native blocks. The draft page bodies are editable content records; the corresponding block-by-block copy is stored under commerce/pages.json for the subsequent theme build. Page creation alone is not evidence that a block template has been implemented.

Before setting template suffixes, create and validate the matching JSON templates in an unpublished development theme. Do not modify or publish MAIN during this foundation phase.

The detailed sitemap, native block mapping and editability acceptance checks are in docs/shopify-structure.md. Homepage, page, collection, product and contact copy are stored in commerce/.

## Storefront state

Initial working mode: internal catalogue and website development. Prices, sizes, stock and release dates are not finalized. The zero amount required for draft variant creation is an administrative placeholder, never retail pricing. Keep inventory tracked and products DRAFT.

The historical plan proposes Netherlands/EU first; the connected trial store is UAE/AED. Resolve that commercial configuration before selling. No exchange-rate conversion, tax, shipping or policy assumptions are approved.

Intended public domain: fann.fashion; secondary recorded domain: fannfashion.com. DNS and redirects are not configured in this step.
