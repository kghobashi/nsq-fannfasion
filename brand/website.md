# Website brief

- Governing content: Bank Gothic and Montserrat; the promise Designed for Confidence. Engineered for Comfort.; the tagline Support in Style.
- Scope constraint: no X Edition navigation, products, imagery, copy or coming-soon teaser in the current website.
- Scope constraint: no erotic-themed underwear or erotic-themed campaign direction for the current release.
- Retained line: Legacy Line; exact products and launch availability remain unspecified.
- Recorded commerce direction: Shopify. A working FANN Shopify store has not been verified.
- Intended primary public domain: fann.fashion. Ownership is recorded in prior sources; current DNS and deployment are unverified.
- Secondary recorded domain: fannfashion.com; redirect behaviour remains unverified.
- Implementation constraint: no invented prices, products, stock, technical claims, reviews, certifications, shipping promises or returns terms.
- Preparation sequence: settle the minimum product and launch inputs, review concept imagery, select one direction, then implement and verify the site.

## Build recommendation

Evaluate a native Shopify theme with custom FANN art direction first. Keep the brand's customer experience distinctive while using clear commerce ownership. GitHub should govern the brand context and source; Shopify should own products, inventory, orders and checkout when the store is established.

Do not introduce a second commerce database without a defined need. Existing Supabase records are supporting operational context, not a substitute for an approved storefront catalogue.

If Shopify GitHub synchronization is used, the connected branch must follow Shopify's supported theme structure. This documentation repository has not yet been converted into a deployable theme branch.

## Provisional page coverage

For a showcase/waitlist: home, brand story, collection or product preview where supported, contact and signup, with appropriate policies.

For a selling store: add accurate product detail, size/fit guidance, cart and checkout, delivery and returns, and customer-support content. This is conditional coverage, not an approved final navigation.

## Verification when implementation begins

Check visual fidelity to the selected concept, mobile layout, keyboard navigation and focus, readable contrast, reduced motion, loading and error states, forms and confirmations, image and font loading, and performance. When commerce is enabled, exercise variant selection, cart and checkout with representative states.
