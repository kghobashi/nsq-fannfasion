# FANN brand context

This directory is FANN's canonical foundation. Version 1.2.0 records the selected Option 3 website direction, seasonal range and domain connection. The 1.1.0 history incorporates the substantive Strategic Updates bible and concept assets supplied on 29 September, while preserving the approved typography, exact messaging and X Edition exclusion from 28 September.

## Authority and approval scope

The latest explicit founder decision governs. A later source document does not silently reverse a founder decision. Approved FANN context governs downstream work; operational databases and cross-brand documents provide supporting evidence and may contain older information.

Canonical status applies to the bounded foundation. Product specifications, collection styling, website launch mode, final imagery, commerce configuration and a final page composition remain open. Proposed content is marked as such.

## Loading order

1. `brand.json`
2. `decisions.md`
3. `identity.md` and `philosophy.md`
4. `voice-and-copy.md` and `visual-system.md`
5. `experience.md` and `website.md`
6. `context-packet.json` for a concise derived handoff

`context-packet.json` is generated, not independently maintained. It is not a source of additional approvals. The package builder extracts bullet items and explicit `OPEN QUESTION:` / `CONFLICT:` lines from the listed source files.

## Changes

Use PATCH for clarification, MINOR for an approved extension, and MAJOR for material repositioning. Record approval basis, exact scope and superseded content in `decisions.md`. Keep the original source receipt when a file is incomplete or replaced.
